## Notes on the columns

* The **FP Type, DET, FTR, Complexity, Weight** columns of the System Design have been **dropped**, following Step 2 item 4:
  they are DBIZ2 cost-estimation tools and tell a coding agent nothing.
* The **Input (DBIZ2)** and **Output (DBIZ2)** columns are translated into English from the Vietnamese System Design v2.0; their meaning is unchanged.
* The two **type and required** columns were added in Session 4. `Req` = required, `Opt` = optional.
* Cells that could not be decided yet are left as they are in DBIZ2; open questions are tracked outside this repository.

## About the Subfunction IDs

DBIZ2 v1.0 used the ID ranges `F-USER-nn`, `F-PROJ-nn`, `F-LOC-nn`, `F-MATCH-nn`, `F-PERM-nn`, `F-ADM-nn`, `F-SYS-nn`
for 110 processing steps. System Design v2.0 reorganises them by capability, so the IDs were reassigned by module:
`F-<MODULE>-nn`. This is a **deliberate change recorded in System Design v2.0**, not arbitrary renumbering.
The v1.0 ↔ v2.0 mapping table is in `docs/architecture/use-case.md`, last section.
